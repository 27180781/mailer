# חיבור ל-Claude (MCP)

המערכת היא שרת MCP. Claude יכול לעבוד בה בשם משתמש, עם כל מה שהמשתמש יכול לעשות בממשק.

כתובת: `https://mail.retsef.co.il/mcp`

## Claude.ai ו-Claude Desktop

1. הגדרות ← Connectors ← **Add custom connector**.
2. מדביקים את הכתובת ולוחצים Add.
3. נפתח דף התחברות של המערכת. מתחברים עם המייל והסיסמה.

ההתחברות היא OAuth 2.1 עם רישום אוטומטי ו-PKCE. Claude מקבל טוקן שמתחדש לבד, עד 90 יום מהשימוש האחרון.

## Claude Code

```bash
claude mcp add --transport http mailer https://mail.retsef.co.il/mcp
```

ואז `/mcp` כדי להתחבר. אפשר גם עם מפתח API של עסק אחד, בלי התחברות:

```bash
claude mcp add --transport http mailer https://mail.retsef.co.il/mcp --header "Authorization: Bearer mk_live_..."
```

## הרשאות

- כל כלי פועל בעסק הפעיל (`whoami`, `switch_account`), לפי ההרשאה של המשתמש בו: בעלים, מנהל, עורך או צופה.
- הכלים קוראים ל-API הרגיל, ולכן כל הבדיקות, המכסות והכללים זהים לממשק.
- כלים ששולחים מייל אמיתי או מוחקים מסומנים כ-destructive, ו-Claude מתבקש לאשר מול המשתמש לפני שהוא מפעיל אותם.
- ביטול גישה: מנתקים את המחבר ב-Claude, או משנים סיסמה.
